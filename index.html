About This App

Algorithm Lab

Algorithm Lab is an interactive educational application for visualizing and comparing core algorithms from Design and Analysis of Algorithms. It turns abstract concepts such as sorting, graph traversal, shortest paths, recursion, dynamic programming, greedy strategies, and backtracking into live step-by-step visual experiences.

The goal of this project is to help students understand how an algorithm makes decisions during execution, not only the final answer. The app supports prepared examples, random data, and custom user input for clearer comparison and experimentation.
